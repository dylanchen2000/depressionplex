在工具 v1.2 就已经修掉了。** 文件头注释原文：

> v1.2 计时模型：在动秒数 = 视频时间轴上按住区间的并集。回看（← 键）与暂停（P 键）

所以：

- `SOP_悬尾实验人工评分_v1.3.md` 第四节末尾那段 DP-006 提示**已过期**，
  SOP v1.4 已改正。v1.3 文件按规矩不删不改，作为已有数据的口径依据留档。

### 还没修的三条里，哪一条真的挡住工作

**只有 DP-027 ①（不能 seek / 不能逐帧）真的挡路**，它挡的是 **T1 精标**：
T1 的定义就是「可暂停、可回看、可逐帧」。暂停和回看已经有了，**逐帧和跳转没有**。
现状下 T1 只能做到「暂停 + ← 键回看」，做不到逐帧核对。
⇒ 上 T1 之前必须先加这两个，否则 T1 名不副实。

DP-008（无撤销）和 DP-027 ②（无早退出口）是效率与体验问题，不影响数据正确性：
按错了就照 SOP 继续按，事后分析用的是区间并集，多按不会偏高。
