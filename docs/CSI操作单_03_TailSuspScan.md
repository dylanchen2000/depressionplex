## 一、开机先确认一件事：你这套是不是能同时做 4 个孔位的版本

手册第 6 章写明：**基础版 TailSuspScan 只能分析 1 个孔位**；
能把 4 个孔位并排同时分析的是 **TailSuspScan H / HR** 版本（H = High-Throughput）。

所以第一件事：

1. `Help → About TailSuspScan`，**截图**，看程序名里有没有 `H`。
2. 不管 About 怎么写，用第 2 节打开一段视频后，按 `Arena → Set Arena Number` 填 **4**：

   | 现象 | 说明 | 怎么办 |
   |---|---|---|
   | 界面下方变成 **4 对**输出窗（每个孔位一对：姿态 + 行为） | 是 H 版，能做 | 走第五节 |
   | 还是只有 1 对，或者不让填 4 | 不是 H 版 | **走第十节的退路**，不要硬试 |

**先把这一条确认了再往下做**，它决定后面是做 7 遍还是 28 遍。

## 二、打开视频：6 项的顺序和游泳那边**不一样**

`File → Open`（或左上角打开按钮）。**不要照抄 02 的表**，悬尾的第 4、5 项是反过来的：

| 项 | 填什么 |
|---|---|
| 1. MPEG Video | `D:\csi_in\TST_20mg_3w_x2.mpg` |
| 2. Background File | **留空**（第六节生成） |
| 3. Current Arena Calibration | **留空**（第五节生成） |
| 4. **Posture Classifier** | TailSuspScan 安装目录下的 `Data\PostClass\DT1.dt` |

| 6. Output Folder | `D:\csi_out\` |

> 游泳那个程序是 **4 = 设置文件、6 = 分类器**；悬尾这个是 **4 = 分类器、5 = 设置文件**。

点 `OK`，弹背景警告点 `OK` 跳过。

## 三、悬尾要单独冻结一份参数

**TailSuspScan 和 ForcedSwimScan 是两个独立程序，参数不通用**，
02 里那份 `CSI默认参数_冻结.set` **不能拿到这里用**，要另存一份。

1. `Tools → Settings`。
2. 面板上有 **5 个标签页**，第一个叫 **`Parameter`**（默认就停在它上面）。
3. **5 个标签页全部截图**，要能看清每个输入框里的数字。
4. **什么都不要改**，点 `Save Settings`，存成 `D:\csi_out\TST默认参数_冻结.set`。
5. **从这一刻起，这个 `.set` 就是悬尾这批唯一的设置**，后面每段视频的第 5 项都填它。
   不再进 Settings 面板，不再改任何数字。

手册给了默认值的（照抄，不用改，只是给你对一眼截图有没有拍全）：

| 参数 | 手册默认值 |
|---|---|
| Component Size Thresh | **200** |
| Intensity Threshold1 | **24** |
| Intensity Threshold2 | 手册说**当前没在用** |
| High Valley Thresh | **20%** |
| Low Valley Thresh | **1%** |
| Histogram Exponential Forgetting Factor | **95%** |
| Frame Border Size | **10** |

**手册没给默认值的，恰好是决定"不动多久"的那一整批**：
`Mobility Thresh`、`Immobility Thresh`、`Mobility / Immobility Combination Limit`、
`Section Size (seconds)`、`Noise Thresh`、`First Combine Limit`、
`Mobility / Immobility Length Thresh`、`BG Gen Thresh`。
手册对这些只说"是相对量，本身没有意义，要靠试错自己定"。

> 所以第 3 步那 5 张截图是**这一份里最重要的交付物**。
> 那些数字只存在于你这台机器的屏幕上，不截图，这批结果将来谁也说不清是怎么来的。

## 四、有两个按钮绝对不要按

视频控制条最右边有三个字母按钮：

| 按钮 | 是什么 | 能不能按 |
|---|---|---|
| **A** | Analysis Mode，分析模式 | **只准停在这个上面** |
| **P** | Posture Training Mode，姿态训练 | **不许按** |
| **B** | Behavior Training Mode，行为训练 | **不许按** |

按了 P 或 B 就进了训练模式，会去改软件判断姿态/行为的那套模型。
**这种改动不会写进 `.set` 文件里**，事后从文件上查不出来，
但之后所有结果都跟前面的不可比了。

**万一误按了，如实说。** 那一段作废重跑就行，只损失一段；
瞒下来会污染全部 7 段。

## 五、校准 4 个孔位（比游泳少 2 个点）

### 5.1 先告诉软件有 4 个孔位

`Arena` 菜单 → `Set Arena Number` → 输入 **4** → 确定。
做对了下面会出现 **4 对**输出窗。只有 1 对 → 停，回第一节。

### 5.2 孔位编号：从左到右

> **Arena 1 = 画面最左边那个孔位，2、3、4 依次向右。**
> 这个顺序不许改，我们自己的数据是按 ch1–ch4 存的，要对得上。

### 5.3 每个孔位只标 4 个点

`Arena` 菜单 → `Calibration` → 弹窗问 `Arena ID to be Operated`，先输 **1**。

在视频画面上**右键单击**位置 → 弹出小菜单 → **左键选**标签。4 个点：

| 顺序 | 右键点在哪 | 选哪个标签 |
|---|---|---|
| 1 | 左上角 | `Arena Top Left Point` |
| 2 | 右上角 | `Arena Top Right Point` |
| 3 | 左下角 | `Arena Bottom Left Point` |
| 4 | 右下角 | `Arena Bottom Right Point` |

**没有 `Split Level`，没有 `Water Top Level`**——那两个是游泳专有的，悬尾这里不存在。

### 5.4 "角"该标在哪：框住老鼠能动到的范围，不是框住孔位边框

手册原话是"四条青色线应该**围住动物能活动的区域**"。悬尾里老鼠倒挂在杆下：

- **上边**：标到挂杆/尾根那个高度，不要把杆子外面一大片空白圈进来；
- **下边**：标到老鼠伸直了也够不到的位置**再往下一点**；
- **左右**：贴着这个孔位的背光亮带，**相邻两个孔位的框不许重叠**——
  重叠了两个孔位会互相抓到对方的老鼠，那两列数据全废。

标完能看到青色的框。**看不到**就到左侧 `Display Option` 区把 `Arena` 那个勾勾上。

点错了不要紧：**在你觉得更对的位置重新右键、选同一个标签**，就覆盖掉前一次，可以反复改。

### 5.5 一个孔位标完必须显式结束

在画面上**右键 → 选 `Stop Calibration for this Arena`**。

**然后整套重来一遍**：`Arena → Calibration` → 输 **2** → 标 4 个点 →
右键 `Stop Calibration for this Arena`。**孔位 3、4 同理。**

> 手册用大写强调了 EACH：每个孔位都要单独走一次 `Calibration` 菜单，不能一次标完四个。

### 5.6 存盘 + 截图

1. `Arena` 菜单 → `Save` → 存成 `D:\csi_out\TST_20mg_3w.CLB`（**后缀必须 `.CLB`**）。
2. **把带着 4 个校准框的整个画面截图，交回来。**

> 截图必须交：我要用它核对 CSI 的 Arena 1–4 和我们的 ch1–ch4 是不是同一个孔位。
> **这个对应关系我这边没有权威记录**，只能靠这张图确认；对错了，后面所有比较
> 都是拿甲的读数比乙的老鼠。
>
> `Arena` 菜单里还有个 `Load Standard`，**不要点**，它会用一套标准参数覆盖你标好的。

## 六、生成背景图（和游泳同一套办法，直接用方法二）

TailSuspScan 手册第 3.2 节自己就写了：**老鼠不够活跃时，自动生成背景（方法一）经常失败。**
悬尾正是这种场景。我也在 Mac 上试过预先算好背景图直接给你，**两种算法都失败了**
（原因写在 00 第六节）。所以：

### 6.1 切到方法二

`Option` 菜单 → `Bkgd Generate` → 选 **`Method 2`**。

### 6.2 拖到视频中间，先取消分析勾选

1. 左侧 `Analyze` 区 4 个孔位的勾选框**全部取消**（不取消就是一边播一边分析，结果会脏）。
2. 进度条拖到**大约一半的位置**。

> 为什么取中间：实测这套录像的背光亮度在一段里会漂 **23–27 个灰阶**，
> 而悬尾判"这是动物"的对比度阈值 `Intensity Threshold1` 默认只有 **24**。
> 背景取中间，它跟全片任何时刻的亮度差最多一半。（00 第七节）

### 6.3 生成，反复接续直到干净

1. `Background` 菜单 → `Generate Background`。
2. 方法二下，临时背景图里**会看到老鼠的一部分**，随时间慢慢消失。
3. 老鼠基本消失了，点 **Stop/Pause** 停止生成。
4. **哪个孔位还留着老鼠影子**：把视频拖到那只老鼠位置不一样的另一个时间点，
   再点 `Generate Background` 接着生成。
   弹出问 **"Do you want to clear history data of Background Generation?"**
   → **选 `No`**（选 `Yes` 前面积累的全丢，从头重来）。
5. 重复第 4 步，直到 4 个孔位里都看不到老鼠。

### 6.4 验收：这张图必须干净

| 看什么 | 合格 | 不合格 |
|---|---|---|
| 孔位里 | 只有背光亮带和挂杆 | 有一团深色的东西（老鼠残影） |

**悬尾这里比游泳更容易失败**：抑郁模型的老鼠可能整段几乎不换位置，
那这个像素上永远看不到背景。所以——

> 某个孔位试了 5、6 次、换了好几个时间点还是清不掉：
> **停，把背景图截图发回来。** 很可能这只老鼠全程没动过位置，那是**结论**，
> 不是操作失误，我要知道这件事。**不要凑合往下走**——
> 背景里留着老鼠等于告诉 CSI"老鼠是布景"，那个孔位的读数会全错，
> 而且表面看不出错，它照样输出一个数。

### 6.5 存盘

`Background` 菜单 → `Save Background` → `D:\csi_out\TST_20mg_3w_bg.BMP`，
**并把这张背景图截图一起交回。**

## 七、跑分析

1. 左侧 `Analyze` 区，**4 个孔位的勾选框全部勾上**。
2. **`UpdateBackground` 勾选框：照屏幕上原样，不要动，但要截图。**

   > 勾上能让背景跟着亮度漂移更新，听起来对；可它的原理是"没被认成动物的部分
   > 就算背景"——悬尾里老鼠长时间不动，很可能被当成背景吸收掉，那不动时长就全废。
   > 两个方向都有风险，**本轮不赌**，保持出厂状态并截图记录。（00 第七节）

3. `AutoStop` **不用**，留空/不启用，我们要跑全程。
4. 点一次 **Step Forward**（单帧前进），**先看一眼** Illustration View
   （只有黑白两色那个窗口）：

   | 现象 | 怎么办 |
   |---|---|
   | 每个孔位一个白色团块，形状像倒挂的老鼠（带尾巴） | 好，继续 |
   | 团块乱七八糟 / 一片白 / 一片黑 / 抓到的不是老鼠 | **停，截图发回来。** 不许调参数硬凑 |

5. 点 **Play**。分析跟着播放跑，比实时慢是正常的。
6. **跑完之前不要双击下面的事件记录。** 手册明说：一双击去回看，
   `Analyze` 勾选框会**自动取消**，分析就停了。
7. 中途停了：用 `GotoFrame` 跳回停下来的那一帧，再点 Play 续跑。
   **已经分析过的片段不能重新分析**（手册明说），只能从断点往后接。
   **不按 `Reset` 不许从头重跑**——不按 Reset 会把两次结果叠在一起。

## 八、导出（一个孔位一次，共 8 次）

跑到视频结束之后：

1. 事件记录窗下面那对单选（time / frames）：**统一选 `frames`。**
   理由：我们的录像是 25 fps，帧号能精确换算成秒，秒的显示可能已经被四舍五入过。
   （如果你已经用 time 导过了，不用重导，**告一声你用的是哪个**就行。）
2. 左侧 `Save` → 弹窗问哪个孔位 → 选 **1** → 存成
   `D:\csi_out\TST_20mg_3w_arena1.MBR`。**孔位 2、3、4 各存一次。**
3. 左侧 `Export` → 对话框**最上面填 `Arena Number` = 1** → 导出 Excel，存成
   `D:\csi_out\TST_20mg_3w_arena1.xls`。**孔位 2、3、4 各导一次。**

> `Save` 和 `Export` 都是**一个孔位一次**，手册明确说的。
> 一次只包含一个孔位的数据，不要以为导一次就全有了。

## 十、其余 6 段：没有批处理，一段一段做

**TailSuspScan 1.0 的 Tools 菜单只有 `Settings` / `Load Settings` / `Save Settings`，
没有 Batch Mode**（有批处理的是游泳那个 2.0）。所以每一段都要完整走一遍：

打开（第二节，第 5 项填冻结的 `.set`）→ 校准 4 个孔位存 `.CLB` + 截图（第五节）
→ 生成背景存 `.BMP` + 截图（第六节）→ 跑（第七节）→ 导 8 次（第八节）。

命名严格照这个来：
`TST_<和视频同名>.CLB`、`TST_<和视频同名>_bg.BMP`、
`TST_<和视频同名>_arena1..4.MBR` / `.xls`

**校准和背景躲不掉**：摄像机位置每段不完全一样，背景亮度也不一样，
不许把一段的 `.CLB` 或 `.BMP` 套到另一段上。

**一天做不完就分天做，不要连着硬撑。** 校准标不准是这一份最大的风险，累了就会标歪。

## 十一、退路：如果不是 H 版（`Set Arena Number` 填不了 4）

那就**一次只做一个孔位**，同一段视频开 4 遍：

1. 第 1 遍：`Set Arena Number` = 1，只标**最左边**那个孔位的 4 个角，
   存 `TST_20mg_3w_a1.CLB`；生成背景存 `TST_20mg_3w_bg.BMP`；跑；
   导 `..._arena1.MBR` / `.xls`。
2. 第 2 遍：重新 `File → Open` 同一段视频，第 2 项**填上刚才那张 `_bg.BMP`**
   （背景跟孔位无关，**可以复用**，不用重新生成），第 3 项留空，
   只标**左边第二个**孔位，存 `..._a2.CLB`，跑，导 `..._arena2.*`。
3. 第 3、4 遍同理，标左边第三、第四个孔位。

工作量是 H 版的 4 倍（7 段 × 4 遍 = 28 遍）。

> **先只做 `TST_20mg_3w` 这一段的 4 遍，交回来，我再决定要不要全做。**
> 28 遍手工校准的返工风险很高，值不值得做由我这边判断，不要自己闷头往下推。

## 十二、遇到下面任何一条，停下来问

1. 画面打不开、或者是黑的；
2. `Set Arena Number` 填了 4 但下面还是只有 1 对输出窗（→ 第十一节，但先问一声）；
3. 相邻孔位的校准框没法不重叠；
4. Illustration View 里的白团和老鼠对不上；
5. 某个孔位的背景图换了好几个时间点还是有老鼠残影；
6. 分析跑到一半自己停了、或者软件崩了；
7. **误按了 P 或 B 按钮**（第四节）——如实说，那一段重跑就行；
8. 某个孔位的结果明显荒唐（全程 100% 不动，或者 0% 不动）。

**第 8 条特别注意：不要因为结果荒唐就去调参数。**
把它记下来、照样导出交回。默认参数下 CSI 算不对，这本身就是我们要的信息。
