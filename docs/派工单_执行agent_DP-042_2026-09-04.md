### 步骤 1：用帧数把切片归到源视频（不靠文件名）

同一段源视频切出来的 4 个切片，**帧数/时长/分辨率完全相同**。这比名字可靠得多。

```bash
ffprobe -v error -count_frames -select_streams v:0 \
  -show_entries stream=nb_read_frames,width,height,r_frame_rate,duration \
  -of default=nw=1 "<文件>"
```

- 27 个切片 + 7 段源视频全跑一遍，把 `(帧数, 宽, 高, 帧率)` 记成表。
- **切片宽度应约为源视频的 1/4**（源实测 476×268，4 隔间横排 ⇒ 每个约 119 px）。
  实际宽度不是 1/4 的（比如有重叠边距、或裁过高度）**照实记下来，不要四舍五入到"应该是"的值**。
- **归组必须是唯一的**。如果两段源视频帧数恰好相同、导致某个切片可以归到两处，
  **不许挑一个**——记成 `歧义`，用别的证据（分辨率、首帧内容）再切一刀，还是分不开就在表里留 `未确认`。

### 步骤 2：模板匹配定 x 偏移 ⇒ 得出"左起第几个"

抽源视频和切片的**第 1 帧**（同一时刻），在源帧上滑窗找切片首帧的位置：

```bash
ffmpeg -v error -i "<视频>" -vf "select=eq(n\,0)" -vsync 0 -frames:v 1 "<输出>.png"
```

```python
import numpy as np
from PIL import Image

src = np.asarray(Image.open("src_f0.png").convert("L"), dtype=np.float64)
pat = np.asarray(Image.open("slice_f0.png").convert("L"), dtype=np.float64)
h, w = pat.shape
# 只沿 x 滑（4 隔间是横排的）；若切片高度 != 源高度，y 也要滑，别假设 y=0
best = min(((np.abs(src[y:y+h, x:x+w] - pat).mean(), x, y)
            for y in range(src.shape[0] - h + 1)
            for x in range(src.shape[1] - w + 1)))
```

- **纯 numpy + PIL 就够，不要引 cv2**（沙箱没有，Mac 上有也别用——保持两边可复算）。
- 判据：最佳位置的**平均绝对误差必须接近 0**（无损裁剪应当**逐像素相等**）。
  如果不是 0，说明切片被重编码/缩放过 ⇒ **照实记下 MAE，并在表里标"非无损"**，
  这时排序仍然可用，但"逐像素对齐"这个结论不许写。
- **必须验证"第二佳"明显差于"最佳"**（比如差一个数量级）。
  背光画面 4 个隔间长得很像，如果第二佳几乎一样好，**这次匹配就是不可信的**，标 `未确认`。
- 由 x 偏移排序 ⇒ 得出该切片是**左起第几个**。

### 步骤 3：交一张表

| 源视频 | 切片文件名 | 帧数 | 宽×高 | x 偏移 | y 偏移 | MAE | 第二佳/最佳 | 左起第几个 | 名字里的 `chk` | **是否一致** |
|---|---|---|---|---|---|---|---|---|---|---|

再加**四个隔间的真实 x 边界**（从 4 个切片的 x 偏移和宽度直接读出来，不要靠"平均分四份"算）：

| 源视频 | 隔间 1 x 区间 | 隔间 2 | 隔间 3 | 隔间 4 | 是否等宽 |
|---|---|---|---|---|---|

**这张表就是交付物本身。** 结论（映射一致 / 不一致）必须从表里看得出来，
不要只给一句"验证通过"。
