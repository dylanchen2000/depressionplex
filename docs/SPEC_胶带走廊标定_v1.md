## 0. 你要解决的问题（一句话）

TST 悬尾视频里，动物悬在一条竖直黑胶带下端。当前 `segment_animal()` **每帧靠形状启发式**去
区分"胶带"和"动物"，在动物剧烈挣扎、频繁碰到胶带时会判错。**相机是固定的，胶带的水平位置
是这段录像的一个常量**——它应该被标定一次，而不是被推断 9661 次。

---

## 1. 现状与实测证据

### 1.1 素材事实

| 项 | 值 |
|---|---|
| 视频 | `~/Work/heavy/depression/悬尾/10mg 2周.mp4` |
| 分辨率 / 帧率 / 总帧 | 476×268 / 25 fps / 9661（≈6.4 min） |
| 布局 | 4 个隔间横排，背光面板（亮白）+ 动物（黑剪影） |
| 隔间列范围（自动检出） | (20,114) (122,215) (254,347) (354,447)，各约 95 px 宽 |
| Otsu 阈值 | ≈137.5（直方图强双峰：0–15 灰阶 37296 px / 240–255 灰阶 52507 px） |
| 胶带宽度 | **6–7 px**（≈隔间宽的 7%） |
| 动物宽度 | **12–16 px**（≈13–17%） |
| 采集端对比度 | 绝对差 **208.5** 灰阶 / 比值 **6.77×**（门槛 100 / 2×，已通过） |

隔间 1 在某帧的实际布局（掩膜，行号为绝对行）：

```
rows 136–150   空白（动物的浅色尾巴在此，阈值下不显影）
rows 151–185   动物，10–14 px 宽
rows 240–258   底部玻璃收集盒（半透明，软边）
```

### 1.2 两批帧的表现差异（这就是问题所在）

**A 批**：帧 600–607（t≈24 s，TST 早期，小鼠剧烈挣扎）→ **2/4 隔间判错**

| 隔间 | 症状 |
|---|---|
| 2 | 挑到了**胶带**：伸展度 10.64、面积 334 px、跨帧零变化 |
| 4 | 不稳：面积 85±57 px、BL 7.1 px、伸展度 1.23 |

**B 批**：视频后段静止期 → **4/4 正常**

| 隔间 | 面积 | BL | 伸展度 | RAD 残差 | 状态 |
|---|---|---|---|---|---|
| 1 | 199±11 | 32.4 | 3.98 | 0.0178 | 较静 |
| 2 | 201±17 | 32.4 | 3.71 | 0.0554 | 在动 |
| 3 | 196±6 | 35.6 | 3.60 | **0.0043** | **真静止** |
| 4 | 177±3 | 20.9 | 2.02 | 0.0367 | 在动 |

结论：**动物剧烈活动、与胶带频繁接触时当前判别失效。**

### 1.3 当前实现在做什么

`depressionplex/assay_core/segment.py::segment_animal()`：

1. Otsu 阈值 → 暗掩膜
2. 定位背光面板行带（`panel_band`，取**最长连续**达标行段）
3. 连通域标记
4. **排除触及 ROI 左/右/下边界的组件**（箱体黑框、收集盒都触边）
5. **取剩下候选中最低的那个**（bbox 底行最大）——因为动物悬在胶带下端
6. 触顶者打 `tape_attached` 标记

第 5 步就是脆弱点：动物与胶带在掩膜里连成一体时，"最低的组件"是"胶带+动物"整体；
动物贴着胶带或蜷在胶带正下方时，也可能整体被当成一条竖直细物。

## 2. 根因

**把本该标定一次的东西，做成了每帧推断。**

相机固定 ⇒ 每个隔间的胶带**列区间**在整段录像里几乎不变。这是几何语义图（`geometry.py`）
该承载的信息，不是分割器该猜的东西。

---

## 3. 设计契约

### 3.1 `geometry.py`：新增语义角色

```python
ROLE_TAPE_CORRIDOR = "tape_corridor"
```

- 允许的几何类型：`KIND_RECT`
- 一个隔间一个实例，`instance` = 隔间序号（1..4），与 `ROLE_CHAMBER` 的 instance 对齐
- 坐标含义：`((x0, y0), (x1, y1))` = 胶带走廊的列区间与行区间（行区间取胶带的**最大**竖直延伸范围）
- 必须登记进 `_ROLE_KINDS`
- **不要**加进 `REQUIRED_ROLES["TST"]`——走廊是可选优化项，缺失时分割应退化为当前行为而非报错

### 3.2 新增标定函数

```python
def calibrate_tape_corridor(
    grays: list[np.ndarray],          # 同一隔间 ROI 的多帧灰度图（建议全片均匀抽 20–40 帧）
    *,
    dark_freq_thresh: float = 0.90,
    ...
) -> TapeCorridor | None:
```

放在 `segment.py`（与 `find_chambers` 同级，都是"标定提案"性质）。

**返回 `None` 而不是猜**——标定失败必须显式。

`TapeCorridor` 建议为 frozen dataclass，至少含 `col_range: tuple[int, int]`、
`row_range: tuple[int, int]`、`confidence: float`。

### 3.3 `segment_animal()` 扩展签名

```python
def segment_animal(
    gray: np.ndarray,
    *,
    corridor: TapeCorridor | None = None,   # 新增
    ...
) -> SegResult:
```

- `corridor=None` → 行为与现在**完全一致**（现有 49 测试必须保持全绿）
- 给了 corridor → 走新路径

`SegResult.flags` 新增取值（按需）：`animal_in_corridor`、`corridor_unused`。

## 4. 推荐实现路径

**这是建议，不是强制。** 只要满足 §5 验收判据，你可以用别的做法，但必须在 PR 说明里
写清为什么换。

### 4.1 标定：靠"暗频率"而非形状

关键观察：**胶带在几乎所有帧都占据同一批列；动物在动，位置在变。**

1. 对抽样帧逐像素统计"暗频率" = 该像素在多少比例的帧里低于 Otsu 阈值
2. 只看面板行带的**上部**（例如上 1/3）——动物很少长时间待在紧贴胶带顶端的位置
3. 走廊列 = 该区域内暗频率 ≥ `dark_freq_thresh`（0.90）的列
4. 走廊行下界 = 仅走廊列内仍保持高暗频率的最低行

> 已验证的判别依据：在面板行带内逐列统计"暗行占比"时，**结构立柱 = 1.00，胶带 = 0.32–0.67**。
> 两者宽度都是 6–7 px，**靠宽度分不开，只能靠占比**。`find_chambers()` 已用同一手法，可参考。

### 4.2 分割：用走廊定位"动物顶端"，再按行截断

难点：动物与胶带连通时，光靠"分类组件"分不开，必须**切**。

1. 逐行统计该行在隔间内的暗像素，区分"走廊内"与"走廊外"
2. `animal_top` = 自上而下第一个满足「走廊**外**暗像素 ≥ k px」的行（k 建议 2–3，需实测）
3. 把掩膜限制到 `rows ≥ animal_top`，再做连通域标记
4. 排除触边组件（保留现有规则），取最大面积组件

按行截断天然解决了连通问题：`animal_top` 以上的胶带被切掉。

### 4.3 必须显式处理的边界情况

| 情况 | 要求 |
|---|---|
| **动物完全在走廊内**（蜷缩在胶带正下方，未横向伸出） | `animal_top` 找不到 ⇒ **不得**默默返回胶带。返回 `mask=None` + reason，或返回并打 `animal_in_corridor` 标记，二者择一但必须显式 |
| **动物爬到走廊上方**（抓着胶带往上爬） | 这是**真实行为**（尾巴/胶带攀爬，C57BL/6 常见），**不要把它设计掉**。应能返回该动物并打标记，供后续事件层使用 |
| 走廊标定失败 | `calibrate_tape_corridor` 返回 `None`；`segment_animal` 退化为无走廊路径并打 `corridor_unused` |
| 走廊与动物大面积重叠 | 打标记，不要静默裁掉动物身体 |

## 6. 已知陷阱（都是实测踩出来的，务必读完）

### 6.1 抖动门可以靠"选错静态物体"假通过

误选底部玻璃收集盒时：面积抖动 0.6 px、RAD 残差 0.0001——门漂亮地通过了，
**因为静态物当然不抖**。所以 `probe_frames` 里有合理性检查（面积占 ROI 比例、伸展度、
跨帧是否真的在变）。**任何"通过"都要连合理性检查一起看。**

### 6.2 静默兜底比报错危险得多

`panel_band()` 犯过两次同类错误，都毫无报错、下游全程挑错对象：

1. 无行达标时直接 `return 0, h-1`（整幅高度）→ 顶/底黑框全被框进来
2. 取"达标行的 min..max"而非**最长连续区段** → 收集盒下方还有一行纯面板达标，
   于是盒区被夹在带内

现在它分级回退、全失败返回 `None`。**新代码请沿用这个纪律：宁可显式失败，不要猜。**

### 6.3 `SegResult` 刻意不返回裸掩膜

分割失败若静默返回空掩膜，下游会当成"动物没动" = immobility，**把失败伪装成信号**。
所以失败是 `mask=None` + `reason`，由上层记 `unknown`。新路径请保持。

### 6.4 恒亮的标记等于没有标记

`narrow_as_tape` 曾用 `tape_width_frac=0.20`（19 px），结果在**每个**隔间都触发。
已改为 0.10。新加标记时想清楚它在正常情况下会不会一直亮。

### 6.5 合成测试全绿 ≠ 真实素材没退化

我曾按"纯胶带的宽度沿高度恒定"来判胶带，合成用例全绿，**但真实素材上把动物误杀了**
（隔间 2 全失败）——因为真实胶带上端有时是较宽的**结头**，宽度并不恒定。
**每次改动都必须同时跑合成测试和 A/B 两批真实帧。**

### 6.6 `Component` 不能用 `in` / `==` 判等

它含 ndarray 字段，`__eq__` 会抛"truth value of an array is ambiguous"。
已标 `@dataclass(frozen=True, eq=False)`，比较请用 `id()`。

### 6.7 分辨率偏低，别指望肢体级细节

每只动物 BL 仅 **17–36 px**。immobility 判定够用（靠对比度救），但不要设计依赖
爪子/趾级细节的判据。

## 7. 不要做什么

| 不要 | 原因 |
|---|---|
| 不要引入 OpenCV / scipy | `assay_core` 刻意只依赖 numpy，保持离线交付与可审计性。视频 I/O 层以后才需要 cv2 |
| 不要上学习式分割（S2） | 采集端对比度 208.5/6.77×、分割噪声底 0.43 px，S1 阈值法实测够用。项目纪律：S2 只在 S1 **实测**失效处启用，且须证明优于 S1 |
| 不要把"胶带攀爬"当噪声消掉 | 那是我们要检测的真实行为（CSI 两份手册都没做，是差异化点） |
| 不要为了让门通过而放宽判据 | 判据里的数字都有实测依据。真过不去就报告过不去，我来判断 |
| 不要在 `assay_core` 里做逐帧自动标定并当权威 | 权威标定是**人工确认过的** `GeometryEnvelope`。自动标定只能是"提案"，`confirmed=False` |
