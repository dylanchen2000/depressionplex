## 2. A8：守卫盯着一份产品根本不读的名册

工人按复核 2 的要求把键集提成了常量：

```python
_MODEL_JSON_KEYS = ("generated_at", "video", "sampling", "gates", "chambers", "reference")
_MODEL_GATES_KEYS = ("contrast", "noise_floor", "area_jitter")
...
```

六个常量都建好了，双向镜像守卫也建好了。**但六处 `_require_keys(...)` 调用
一个都没改，全都还在传行内字面元组。** 于是常量一个产品读者都没有，
守卫盯的是一份产品从来不读的名册。

变异实测（`/tmp/dp109mut` 副本，基线 18 通过 0 失败）：

| id | 变异 | 结果 |
|---|---|---|
| **N12** | **从行内元组里删一个键（这是产品真会走的那条路）** | **18 通过 0 失败 —— 全绿，洞在这里** |
| N12b | 只从 `_MODEL_GATES_KEYS` 里删一个键（产品行为不变） | 红 1 |

这和 A5 是同一个形状：红的那次没改变产品行为，改变产品行为的那次不红。
按共同约定 §6，**能红在没人走的那条路上的守卫等于装饰**。

### 我的修法（机械，不动口径，没退回工人）

1. 六处调用全部改成传常量（`_require_keys(gates, _MODEL_GATES_KEYS, "gates")`），
   常量块上写明为什么必须这样传；
2. 新增守卫 13b `test_require_keys_only_takes_model_key_constants`：AST 取出所有
   `_require_keys` 调用，第二个实参只许是 `_MODEL_` 开头的 Name，
   行内元组 / 切片 / 列表一律举报；
3. 改掉镜像守卫 docstring 里的一句假话 —— 它写着「M12 模型 `_require_keys`
   少一个键 ⇒ 本条红」，实测不红。**守卫声称自己防住了没防住的事，比没有守卫更难查。**

证明我的修真的堵住了洞（基线 19 通过 0 失败）：

| id | 变异 | 结果 |
|---|---|---|
| P12 | 常量里删一个键（现在 == 产品行为） | 红 1（镜像守卫） |
| P12c | 把行内元组写回去 | 红 1（13b，`Tuple`） |
| **P12d** | **行内元组 + 少一个键（原洞的完整形状）** | **红 1** |
| P12e | `list(_MODEL_GATES_KEYS)[:2]` 绕一下 | 红 1（13b，`Subscript`） |

## 3. 一条我判定「不算问题」的变异

| id | 变异 | 结果 | 判定 |
|---|---|---|---|
| N7 | `engine.py` 里改成 `getattr(sys, "frozen", False)` | 红 1 | 守卫有效 |
| N7b | 改成 `sys.__dict__.get("froz" + "en")` | 绿 | **不算发现** |

理由：N7b 是刻意的字符串拼接混淆。守卫的职责是拦住「有人顺手把冻结态判定
换了个写法」，不是拦住「有人故意躲开守卫」。所有**可能被自然写出来的拼法**
（`sys.frozen`、`getattr(sys, "frozen", ...)`、`hasattr`）都已经被抓住。
把这条记下来，是因为不写下来，下一轮复核会把同一次绿重新当成新发现。

## 4. 本轮我另外改的两件事（都不在 A1–A11 里）

### 4.1 台账 DP-107 有两个裸行首（合 main 后守卫变红）

`test_issues_md_no_duplicate_numbers` 在合入 main 后红了，报 `DP-107 出现 2 次`。

- 把「一个编号只许一个裸行首」这条规矩写进台账开头，并指明守卫位置 ——
  否则 DP-108/109/110 验收时会各踩一次同一个坑。

### 4.2 被 `AcqCheckPage` 顶掉的占位页还留在仓里

`pages/placeholders.py` 的 `SelfCheckPage` 自 AcqCheckPage 上线起就没有 import 者

测试变红 —— 这正是问题：下一个人照侧栏「自检」去找页面，会先摸到那个只写着
「本页由 B7 交付」的空壳，照它改完发现界面上没反应。**七页名册只许有一份**
（`PAGE_ORDER` / `PAGE_CLASSES`），占位类是名册外的第二个答案。

新增守卫 20 `test_no_orphan_placeholder_pages`：AST 取 placeholders.py 里定义的
