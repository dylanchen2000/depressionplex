# 派工单 B2：新建实验向导 + `experiment.json` 契约（DP-101）

> **本单适用 `docs/派工单/_共同约定_v1.md` 全文**，下面只写本单特有的。
> **分支（写死，不许自己改名）**：`feat/dp101-new-experiment-wizard`
> **基线**：`integration/product-base`（B1 外壳骨架、B3a 引擎新参数都已在这条线上）
> **上游/下游**：上游是 B1（`desktop/` 骨架已交付）；下游是 B3（队列页拿 `experiment.json` 起子进程）。
> **不许动引擎**（`depressionplex/`）一个字节。本单是纯外壳 + 一个契约文件 + 测试。

## 1. 背景（为什么有这一单）

M1「能跑完一场」= B3a + B2 + B3 + B4。B3a 已交付：引擎有了 `--progress-json` 与 `--run-json`。
现在缺的是**把客户的意图变成一份机器可读的分析计划**——这就是 `experiment.json`。

它是 B2 与 B3 之间**唯一**的接口：B2 只写它，B3 只读它。B3 不许问 B2 要任何别的东西，
B2 也不许自己起分析进程。这样两单可以并行、各自可测。

## 2. 要做什么

### 2.1 `experiment.json`（v1 契约，键名照抄，不许自己改）

```json
{
  "schema_version": "1",
  "created_at": "2026-09-13T14:22:31+08:00",
  "operator": null,
  "note": null,
  "assay": "TST",
  "n_chambers": 4,
  "calib_frames": 12,
  "body_area_prior": null,
  "output_dir": "/绝对/路径/2026-09-13_TST批次1",
  "videos": [
    {"path": "/绝对/路径/a.mp4", "trial_prefix": null},
    {"path": "/绝对/路径/b.mp4", "trial_prefix": "自定义前缀"}
  ]
}
```

硬要求：

| 项 | 要求 |
|---|---|
| 路径 | **一律绝对路径**（`Path(...).resolve()`）。相对路径在子进程里以另一个 cwd 解释，会找不到文件或写错地方 |
| `created_at` | ISO 8601 **带时区偏移**，不许写 naive 时间（审计包要跨机对时） |
| `operator` / `note` / `body_area_prior` / `trial_prefix` | 没填就是 `null`，**不许写 `""` 或 `0`**（共同约定 §1） |
| `n_chambers` / `calib_frames` | 整数，界面给默认值 4 / 12，允许改；`< 1` 当场拒绝并说明，不许写进文件 |
| **不许有计分窗口字段** | 窗口由 `assay` 唯一决定（见 2.2）。文件里出现任何 `window` / `scoring_window` 键即算违规，有测试守 |
| 已存在 | 目标目录已有 `experiment.json` 时**报错不覆盖**（提示用户换目录或改名）。静默覆盖等于抹掉别人的实验计划 |
| 键顺序 | 照上面的顺序写（`json.dump(..., indent=2, ensure_ascii=False)`），diff 好读 |

写在哪：用户在向导里选的 `output_dir` 下，文件名固定 `experiment.json`。
`output_dir` 由 B3 用作 CSV / run.json / 时间线的落盘目录，所以它必须可写——
向导里就要试写（建目录 + 写一个临时文件再删），不可写当场报错。

### 2.2 计分窗口：显示，但**不许可编辑**

窗口是范式属性，不是用户选项：TST 全程 `0–360 s`，FST 只计后四分钟 `120–360 s`。
向导里必须**显示出来**（客户要知道自己在算什么），但只能是只读文本，
**不许出现任何能改它的控件**（输入框 / 下拉 / 勾选）。

外壳不许 import 引擎（进程边界），所以这张表在外壳里抄一份，**放且只放一处**：

```python
# desktop/app/assays.py
# 与引擎 trial_report.ASSAY_WINDOWS 同源；对不上时 tests/test_experiment_contract.py 会红。
ASSAY_WINDOWS_UI: dict[str, tuple[float, float]] = {
    "TST": (0.0, 360.0),
    "FST": (120.0, 360.0),
}
```

抄一份就必须有守卫防漂移，见 2.4。**别处不许再抄第二份**（页面里要用就 import 这个）。

### 2.3 向导页面（替换 B1 的占位页）

新文件 `desktop/app/pages/new_experiment.py`，类名仍叫 `NewExperimentPage`（`PAGE_ORDER` 不动）。
`desktop/app/main_window.py` 的 `_CLASSES` 改成从新模块 import 它，并把
`placeholders.py` 里的旧 `NewExperimentPage` **删掉**（留着就是两个同名类，
哪个被用取决于 import 顺序——这正是本仓最不要的那种不确定性）。

四步，一页也行、`QWizard` 也行，你定；但这四件信息必须都收到、都能改、都有校验：

1. **范式**：`TST` / `FST` 二选一（选项从 `ASSAY_WINDOWS_UI` 的键生成，不许写死两个字面量），
   选完立刻在旁边显示只读的窗口文本（例：`计分窗口 120–360 s（FST 前 2 min 适应不计）`）。
2. **视频**：多选文件加入列表，可删、可排序；每行可选填 `trial_prefix`（空 ⇒ `null`，
   引擎会用文件名）。同一条路径重复加入要去重并提示。**一个视频都没有时不许允许「完成」**。
3. **隔间数 / 标定帧数 / `body_area_prior`**：三个数字，后者可空。
   `body_area_prior` 旁边写清它是硬件规格级的绝对先验，平时留空。
4. **输出目录 + 操作者 + 备注**：目录必须可写（见 2.1），操作者与备注可空。

「完成」时写出 `experiment.json`，并把它的绝对路径**发一个 Qt 信号**
`experiment_created = Signal(str)`（B3 会接它，本单只管发出来，不许自己去起分析）。

### 2.4 测试（新建 `tests/test_experiment_contract.py`，登记进 `run_tests.py`）

本仓测试环境**没有 PySide6**，所以这些测试**不许 import 任何 `desktop.*`**，
一律 AST 静态解析（照 `tests/test_desktop_boundary.py` 的写法）。
测试可以 import 引擎（`tests/` 不受进程边界约束），这正是防漂移的关键。

必须有这几条，每条都要能被变异测试打红：

| 守卫 | 断言 |
|---|---|
| 窗口表不许漂移 | AST 取 `desktop/app/assays.py` 的 `ASSAY_WINDOWS_UI` 字面量，与 `trial_report.ASSAY_WINDOWS` **逐键逐值相等**（键集合、数值都比）。任何一边改了都红 |
| 范式选项不许硬编码 | `new_experiment.py` 里不许出现 `"TST"` / `"FST"` 字符串字面量（选项必须从表生成）。**例外**：注释与文档字符串不算 |
| 契约字段对得上引擎 CLI | AST 取 `depressionplex/cli/analyze.py` 里所有 `ap.add_argument("--x", …)` 的旗标集合，断言映射表里每个 `experiment.json` 键对应的旗标**真的存在**。映射表写在测试里：`assay→--assay`、`n_chambers→--chambers`、`calib_frames→--calib-frames`、`body_area_prior→--body-area-prior`、`videos[].trial_prefix→--trial-prefix` |
| 契约里没有窗口字段 | 契约的键集合（从 `desktop/app/models/experiment.py` 的 `SCHEMA_KEYS` 元组静态取）里不许出现含 `window` 的键 |
| 契约键集合被锁住 | `SCHEMA_KEYS` 必须与本派工单 2.1 列的键**完全一致**（测试里写死这份清单）。加字段就得改测试——这是故意的，契约不许悄悄长 |
| 写出的文件符合契约 | 不起 GUI：`desktop/app/models/experiment.py` 里的序列化函数必须是**纯函数**（输入 dataclass / dict，输出 dict 或写文件），测试直接调它；验证绝对路径、`created_at` 带时区、空值是 `null` 不是 `""`、已存在时抛错不覆盖 |

> 上面最后一条隐含的结构要求：**序列化逻辑不许写在 Widget 里**。
> 放 `desktop/app/models/experiment.py`，只用标准库（`json` / `dataclasses` / `datetime` / `pathlib`），
> 不 import PySide6 —— 这样它能被无 GUI 环境直接测。Widget 只负责收集与调用。

## 4. 本单特有的禁令

1. **不许在外壳里解码视频、取帧、做任何图像处理**——包括 `QtMultimedia`。
   理由：引擎（`video.probe` / `iter_gray`）是唯一解码器，第二个解码器会在帧号与 fps 上
   给出另一套真值，那是本仓最贵的一类 bug。所以 **M1 的向导没有预览帧、没有悬挂点/水面人工确认**
   （架构 §6.1 的 B2 行里写了这一项，我在本单**明确移出**，改由后续 B2b 用引擎导出的 PNG 做，
   见 ISSUES 的 DP-103）。向导里可以显示文件名/大小/时长（时长也不许自己解码——留空或不显示）。
2. **不许出现可编辑的计分窗口控件**（窗口由范式定；FST 窗口口径本身还在裁决中）。
3. **不许在向导里起分析进程、不许 import `subprocess`**（起进程是 B3 的事）。
4. 不许把 `experiment.json` 写进缓存目录（`user_cache_dir` 不许放唯一副本）。
5. 不许改 `depressionplex/`、`.github/workflows/`、`desktop/main.py` 的自检判定逻辑。
   `main_window.py` 只许改 `_CLASSES` 的 import 那一处。
6. 不许 `git add -A`；只 add 你真正改的文件。

### 4.2 那条页面守卫怎么改（唯一允许你改测试的地方）

`tests/test_desktop_boundary.py::test_seven_pages_declared_once` 现在只从
`placeholders.py` 收类名。改成：**扫 `desktop/app/pages/*.py` 全部文件**收 `ClassDef` 名，
并且额外断言 `PAGE_ORDER` 里的每个类名在这些文件里**只定义一次**（重名即红）。
守卫只许变严，不许变松——原来的两条断言（7 个页面、显示名不重复）一个字不许动。
