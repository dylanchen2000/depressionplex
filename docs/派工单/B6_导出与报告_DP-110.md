## 0. 架构师先裁的五件事（不许自行改动，改了要退回）

### 0.1 分层：内容层纯标准库，渲染层薄

| 层 | 文件 | 依赖 | 谁验 |
|---|---|---|---|
| 内容层 | `desktop/app/models/report.py` | **只用标准库** | 沙箱全测（本单的守卫全在这一层） |
| xlsx 渲染 | `desktop/app/services/export_xlsx.py` | `openpyxl`（沙箱有 3.1.5，**回读断言**） | 沙箱 |
| PDF 渲染 | `desktop/app/services/export_pdf.py` | PySide6 的 `QPdfWriter` + `QTextDocument` | **只有 CI** |
| 审计包 | `desktop/app/services/export_audit.py` | 标准库 `zipfile` + `hashlib` | 沙箱 |

内容层产出一个纯 Python 的报告模型（章节 + 行 + 声明文本 + 清单），
三个渲染器**只摆不算**。**一个 `+`、一个 `/`、一个 `round()` 都不许出现在渲染层。**

- **PDF 不引第三方库**：`QPdfWriter` 是 PySide6 自带的，已经在包里，不额外增加打包体积与许可风险。
- **xlsx 用 `openpyxl`**：加进 `pyproject.toml` 的 `[project.optional-dependencies]`，**新起一个 `export = ["openpyxl>=3.1"]`**。
  **不许在 pyproject 里写 PySide6 的版本** —— 那个版本号现在只有 CI 工作流一份（`PySide6==6.7.3`），
  在这里再写一遍就是两份来源。
- **打包侧（把 openpyxl 打进 GUI）不在本单范围**：`packaging/` 正由 B10 在改，你**一个字都不许碰**。
  在 PR 正文里写一行「openpyxl 需要进 GUI spec 的 hiddenimports」，那条缝由我合的时候接。

### 0.2 数字的来源：一律是引擎已经写在盘上的那份，导出不许重算

| 要印的东西 | 唯一来源 |
|---|---|
| 所有秒数、帧数、`validity_status`、`scored` | `<stem>.csv` 的 16 个字段（读法用 B4 的 `models/results.py`，**不许自己再写一个 CSV 解析器**） |
| θ_mob、计分窗口、`tool_version`、隔间几何、`plan_warnings`、未产出数字的隔间与原因 | `<stem>_run.json`（同上，走 B4 的模型层） |
| 解码器身份（B10 会加的 `decoder` 块） | `run.json`。**取不到 ⇒ 印「未知」，不许留空冒充「没有问题」** |
| 发布态、徽章、G7/G8/G11 读数与门槛 | `services/calibration.py`（**不许自己判、不许写死「研究版」字样**） |
| 四个引擎产出文件的路径 | `services/engine.output_paths()` |
| 采集自检读数（若客户跑过） | B7 的 `models/self_test.py`。没跑过就印「本机未做采集自检」 |

**合计/均值这一类，本单允许算，但只许算在内容层、且必须与逐试次数字同页并排印**
（例如 4 个隔间的 immobility 均值）。**跨录像、跨批次的统计不做** —— 那要先定清纳入排除规则，不是导出的事。
每个算出来的数都必须在报告里注明「由本页 N 行算得」。

**B4 的 PR #94 正在按复核意见改**（8 条），你依赖它的模型层：
先 `git fetch`，若 `feat/dp107-results-page` 还没合入 main，就以**它最新的 head** 为基开分支，
并在 PR 正文里写明你基在哪个 commit 上。**不许自己复制一份它的解析代码。**

### 0.3 文件名与发布态后缀只许有一处派生

§4 规定研究模式导出的文件名带 `_research`。这个词**必须来自 `calibration.Mode` 的取值**，
不许写字面量。导出文件名清单集中成 `services/export.EXPORT_SUFFIXES`（照
`engine.OUTPUT_SUFFIXES` 的样子），全仓只此一处；守卫查 AST，别处出现
`".xlsx"` / `".pdf"` / `"_审计包"` / `"_research"` 字面量即红。

### 0.4 报告里必须有的三张表 + 必须有的声明（文案我写，见 §2，逐字照抄）

1. **逐试次表**：每个隔间一行，秒数**紧跟它的分母列**（照 B4 的 `DENOMINATORS`，
   **直接 import 它，不许再抄一份**）。**未产出数字的隔间必须在表里，占一行，写原因** ——
   报告里少一行动物，比报错严重得多。空值印 `—`，**永远不许印 0**。
2. **运行上下文表**：`tool_version`、assay、计分窗口、θ_mob 及其标定来源、
   视频名/fps/`frame_count_source`、隔间几何来源、`plan_warnings`、解码器身份。
3. **发布态与验证读数表**：徽章、发布态、G7/G8/G11 的读数与门槛（G11 门槛现为 `None` ⇒
   印「未定」，**不许印 0、不许印空**），以及我们自己的验证读数（§2 的表）。
   **必须写明那些读数来自我们的验证批次，不是客户这批数据的误差** ——
   客户看到「MAE 24.63 s」会以为是他这次跑出来的。

**声明必须印在 PDF 第一页、xlsx 的第一个工作表最上方、审计包的 `声明.txt` 里**，
三处是同一份文本，**只许有一个来源**（`models/report.py` 里的一个常量，或一个随包的 `.md`；
选哪个由你定，但守卫要证明三处印的是同一份字符串）。

**声明是模板，不是一段写死的话**：§2 里所有带数字的地方我都标了 `{占位符}`，
数字一律由 `data/validation_readings.json` 填进去。
守卫要断言**模板文本里不出现那些读数的数字**（否则改了 JSON 而声明照旧印旧数，
是这份文件最难被发现的错法 —— 它印得漂漂亮亮，只是数字过期了）。

### 0.5 PDF 缺字不许悄悄印成空白方块

中文 PDF 在缺中文字体的机器上会印出一片豆腐块或空白，**而文件照样生成成功**。
这正是本仓最忌的失败形状（不报错、看着正常、内容是错的）。

规则：渲染前按 **微软雅黑 → 宋体 → Noto Sans CJK SC** 的顺序找字体，
用 `QRawFont.supportsCharacter()`（或等价手段）**实测一个汉字能不能渲**；
三个都不行 ⇒ **拒绝导出 PDF**，弹一句「本机缺中文字体，已找过这三个：…；
xlsx 与审计包不受影响，可以先导那两个」。**不许降级成拉丁字体硬印。**
架构 §6.1 那句「pdf 可无字体报错生成」指的就是这条：**要么印对，要么明确报错，不许中间态。**

## 2. 声明文案（我写的，逐字照抄；`{}` 里的东西从 JSON 填）

> ### 研究用途声明
>
> 本报告由 DEPRESSION-PLEX **研究版**生成。本软件当前**没有计量资质**，
> 报告中的秒数**不得**作为计量结果、申报材料或合规证据使用。
>
> **为什么是研究版**：签发计量资质的前置条件之一是「逐秒时间对齐门」（G11）
> 必须有一个实数门槛，而它现在**未定**（待人工精标档 T1 定标）。
> 只有总量门（相关系数 G7 门槛 {g7_threshold}、总体偏差 G8 门槛 {g8_threshold_s} 秒）
> 全过**不足以**签发资质 —— 我们实测过一个反例：同类商业软件在
> {csi_n} 个**强迫游泳**试次上相关系数 {csi_r}、总体偏差 {csi_bias_s} 秒
> （两个总量门都过），平均绝对误差却有 {csi_mae_s} 秒，
> 并且把一个**只有水、没有动物**的杯位报成 {csi_empty_cup_s} 秒不动
> （占全窗 {csi_empty_cup_pct}%）。**总量对、时间错的软件能过总量门，
> 过不了任何科学审视。**
>
> **我们自己量到的一致性（这是我们验证批次的读数，不是您这批数据的误差）**：
> 在 {own_n_trials} 个**悬尾**试次（可配对 {own_n_paired} 个）、
> 人工评分为常规档（T2）与对标档（T0）混合的条件下 ——
> 软件与人工的**总体偏差 {own_bias_s} 秒**（几乎不偏，回归斜率 {own_slope}），
> 但**逐试次绝对偏差平均 {own_mae_s} 秒**（范围 {own_err_min_s} … {own_err_max_s} 秒），
> 逐试次达标（≤{g8_threshold_s} 秒）**{own_pass_n} / {own_n_paired}**。
> 同一批数据上，**两位人工评分员之间**的差异极差中位 {rater_median_s} 秒、
> 最大 {rater_max_s} 秒 —— 尺子本身也有这么宽。
>
> **怎么用这份数字才是安全的**：
> 1. **组间趋势、批内比较**可以用；**单个试次的秒数不要单独作为结论依据**。
> 2. 发表或对外报告时，请**同时报出**本声明中的偏差数字，以及您自己的人工标定结果。
> 3. 报告中每个秒数都带着它的**分母**（窗口帧数、可评分帧数、帧率）与
>    `validity_status`。**分母不看，秒数没有意义。**
> 4. **没有产出数字的隔间会在表里占一行并写明原因。**
>    那一行不是「零不动」，是「这一只没有测到」—— 两者在数据上完全不同。
> 5. 判定阈值 θ_mob = {theta_mob} 是**冻结值**，标定来源见「运行上下文」表。
>    它当前的标定锚在混合档人工标签上，**待 T1 精标档重新定标**。
>
> **本软件不做的事**：不做跨录像/跨批次统计，不做组间显著性检验，
> 不替您判断某只动物该不该排除。这些都需要先定清纳入排除规则，属于分析而非测量。

## 3. 测试（每条都要能被变异打红）

1. **声明三处同源**：xlsx 回读、PDF 内容层文本、审计包 `声明.txt` 三份字符串**逐字相同**，
   且都等于那一个来源。变异：改动其中一处的文案 ⇒ 必须红。
2. **声明里的数字来自 JSON**：把 `validation_readings.json` 里的 `+1.74` 改掉，
   断言报告内容层跟着变（证明不是写死的）。
3. **验证读数与文档一致**：正则从 `docs/STATUS.md` / SOP §11 抓 1.74 / 35.15 / 5 / 26 / 19.33 / 66.79，与 JSON 比对。
4. **未产出数字的隔间必须占一行**：run.json 名册 4 个、CSV 只有 2 行 ⇒ 报告逐试次表 **4 行**，
   缺的两行有原因。（这正是 B4 复核 F1/F2 那个洞，**不许在报告层重犯**。）
5. **空值不许印 0**：`immobility_s=""` ⇒ xlsx 单元格回读是 `—`（或空），**不是 `0`/`0.0`**。
   这条要**回读 xlsx 文件**断言，不许只断言内容层。
6. **分母不许再抄一份**：AST 守卫 —— `models/report.py` 必须 `import` B4 的 `DENOMINATORS`
   并以 `ast.Load` 用到它，且本模块内不许再出现同名字典的赋值。
7. **发布态后缀单一来源**：AST 守卫 —— `"_research"` / `".xlsx"` / `".pdf"` 字面量只许出现在
   `services/export.py`；且 `_research` 必须由 `calibration.Mode` 的值拼出来（变异：写死字面量 ⇒ 红）。
8. **G11 未定不许印成 0 或空**：`gates.G11.threshold is None` ⇒ 报告文本里出现「未定」，
   且**不出现 `0`**。变异：兜底成 0 ⇒ 红。
9. **审计包清单**：zip 成员齐（缺哪个引擎产出就在 MANIFEST 里标 `null` + 一行原因，**不许悄悄少装**）；
   每个成员的 sha256 与实际文件重算一致；**MANIFEST 只有一个序列化器**。
10. **解码器未知不许留空**：run.json 没有 `decoder` 块 ⇒ 报告印「未知」（变异：印空串 ⇒ 红）。
11. **PDF 字体缺失 ⇒ 拒绝导出**：把字体查找函数替成「三个都找不到」，
    断言抛出可读异常且**没有生成任何 .pdf 文件**（变异：改成硬印 ⇒ 红）。
    这一条**必须能在没有 PySide6 的沙箱里跑** ⇒ 字体决策要放在一个**纯函数**里
    （输入「哪些字体可用」，输出「用哪个或拒绝」），Qt 只负责问系统。
12. **端到端**：真跑一次引擎（照 `tests/test_analyze_cli.py` 的合成路子）产出 CSV + run.json，
    **用真产物**导出 xlsx 与审计包，回读断言。**不许拿手写假夹具当唯一夹具**（DP-102 就是这么绿着交出错数字的）。
