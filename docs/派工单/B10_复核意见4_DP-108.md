### D1 `test_human_agreement.test_union_equivalence_with_salvage_tool`

**报错**：
```
tests/test_human_agreement.py:48 in _load_salvage_ref
    spec.loader.exec_module(mod)
depressionplex/cli/salvage_truncated_audit.py:22 in <module>
    from . import _stdio
ImportError: attempted relative import with no known parent package
```

**定性：测试的加载方式错了，产品是对的。**

`tests/test_human_agreement.py:39-49` 的 `_load_salvage_ref()` 用
`importlib.util.spec_from_file_location("salvage_ref", p)` **按文件路径**加载一个包内模块，
这样 `__package__` 是空的，模块里任何 `from . import X` 必然炸。
而 `salvage_truncated_audit.py:22` 的 `from . import _stdio` 是**正确**的包内相对 import。

架构师已经全仓扫过（证据）：`depressionplex/cli/` 下 11 个模块都是
`if __name__ == "__main__"` + 相对 import 的形状，但**全仓 0 处**用
`python <路径>/cli/xxx.py` 这种脚本方式调用它们——桌面端走
`desktop/app/services/engine.py:120` 的 `[sys.executable, "-m", "depressionplex.cli"]`，
冻结后走 exe，`-m` 会把 `__package__` 设对。所以按文件路径加载模拟的是一种
**没有任何人使用的调用方式**。

**改法**：`_load_salvage_ref()` 改成
```python
import importlib
mod = importlib.import_module("depressionplex.cli.salvage_truncated_audit")
```
同时**删掉**里面那个「旧路径 `cli/salvage_truncated_audit.py` 兜底」的 for/else 死分支
（DP-030 之后那个路径不存在了，兜底分支永远走不到，是装饰）。

**这不是把守卫改松**：这条测试的判据是「`union_holds` 与抢救工具的 `union_seconds`
逐案等价」，改 import 方式一个字都没动这个判据，300 轮随机对比照跑。

**变异**：把 `union_holds` 的并集逻辑改成朴素求和 ⇒ 本条必须红。

### D2 `test_packaging_contract.test_no_hardcoded_ffmpeg_tool_names`

**报错**：
```
video.py:139 (probe): 出现字符串常量 'ffprobe'。除 _resolve_ffmpeg_tool 外不许直接用工具名字面量
video.py:186 (decode_cmd): 出现字符串常量 'ffmpeg'。除 _resolve_ffmpeg_tool 外不许直接用工具名字面量
```

**定性：守卫太粗，产品是对的。**

被举报的两行是：
```python
# depressionplex/video.py:139
ffprobe, _ = _resolve_ffmpeg_tool("ffprobe")
# depressionplex/video.py:186
ffmpeg, _ = _resolve_ffmpeg_tool("ffmpeg")
```
这是**调用解析器**，正是这条守卫想要的形状。守卫（`tests/test_packaging_contract.py:790-834`）
用 AST 找所有 `ast.Constant` 值等于 `"ffmpeg"` / `"ffprobe"` 的地方，
于是把「传给 `_resolve_ffmpeg_tool` 的实参」也一起举报了。

**改法**：守卫加一条例外——**作为 `_resolve_ffmpeg_tool(...)` 调用的实参出现的字面量，
不算违规**。实现上先收集所有 `ast.Call` 里 `func` 名为 `_resolve_ffmpeg_tool` 的
`args` 节点 id，扫描时跳过这些节点。**不许**用「跳过 `probe` 和 `decode_cmd` 两个函数」
或「跳过 video.py 整个文件」来绕——那是把守卫改松，正好踩共同约定 §6
「不是把守卫改松，而是把代码改成守卫看不见的形状」的反面。

守卫真正要拦的是这种：
```python
cmd = ["ffmpeg", "-v", "error", ...]   # 直接拿字面量拼命令 ⇒ 必须红
```

**变异（两条都要做）**：
1. 把 `video.py:187` 的 `cmd = [ffmpeg, ...]` 改成 `cmd = ["ffmpeg", ...]` ⇒ 本条必须红。
2. 在 `depressionplex/` 下任意别的模块里写一行 `subprocess.run(["ffprobe", ...])` ⇒ 本条必须红。

### D4 `test_packaging_contract.test_run_json_decoder_block`

**报错**：`AssertionError: decoder 块缺 ffmpeg_path`（`tests/test_packaging_contract.py:354`）

**定性：这是契约裁决，架构师已裁决。测试是旧契约，产品是新契约，改测试。**

两种形状打起来了：

| | 形状 |
|---|---|
| 测试期望（`:354-361`） | **扁平**：`decoder.ffmpeg_path` / `decoder.ffprobe_path` / `decoder.source` / `decoder.ffmpeg_version` |
| 产品实际（`depressionplex/cli/analyze.py:255-267`） | **按工具嵌套**：`decoder[TOOL_FFMPEG] = {path, source, version}`、`decoder[TOOL_FFPROBE] = {...}`、外加 `decoder["mixed_source"]` |

**裁决：以嵌套形状为准，测试重写。** 理由：扁平形状只有**一个** `source` 键，
表达不了「两个工具来源不同」这件事，而 A4 明确要求两个工具各自解析、各有 source，
并且要能报出 `mixed_source`（只设了 `DPX_FFMPEG` 却漏了随包 ffprobe，这是真会发生的事故）。
扁平形状会把这种混用**抹平成一个值**——共同约定 §1「未知不许长成数字的样子」的同类问题：
两个不同的来源不许长成一个来源的样子。

**已核对过没有下游依赖扁平形状**：`feat/dp110-export` 分支上唯一的消费者是
`desktop/app/models/report.py:420` 的 `getattr(results, "decoder_info", None)`，
拿的是一个已经格式化好的字符串，不碰这些键。所以改测试是安全的。

**改法**：把 `test_run_json_decoder_block` 重写成断言嵌套形状：
- `decoder` 里有 `TOOL_FFMPEG`、`TOOL_FFPROBE`、`mixed_source` 三个键；
- 两个工具块各有 `path` / `source` / `version` 三个键；
- `_get_ffmpeg_version` 取不到时 `version` **是 `None` 不是 `""`**（这条原测试有，保留，很重要）；
- 两个工具 source 不同时 `mixed_source is True`，相同时 `is False`——**两个方向都要断**，
  只断一个方向的话，把 `mixed_source` 写成常量 `True` 也能过；
- **反向断言**：`"ffmpeg_path" not in decoder`，附错误信息「decoder 块不许再被拍平，
  扁平形状表达不了两个工具来源不同（A4）」。防止有人日后又拍平回去。
- 键名从 `video` 模块的 `TOOL_FFMPEG` / `TOOL_FFPROBE` 常量**现读**，不许在测试里抄字面量；
  但**另加一条**测试把常量的值钉死一次（`assert video.TOOL_FFMPEG == "ffmpeg"`）——
  共同约定 §6「常量被读到 ≠ 值是对的」，两件事都要做。

**变异（三条）**：
1. 把 `analyze.py` 的 decoder 块拍平成扁平形状 ⇒ 反向断言必须红。
2. 把 `mixed_source` 写成常量 `False` ⇒ 必须红。
3. 把 `version` 取不到时写成 `""` ⇒ 必须红。
