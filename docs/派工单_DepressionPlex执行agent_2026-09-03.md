## 2. B 轨：人工一致性（DP-012 → DP-013，立即开工）

**分支**：`feat/human-agreement`，从 `main` 开

### DP-012（第一个 PR）：校验器 + 并集重算。**不算任何一致性指标**

必须实现的四条硬规则：

1. **一律丢弃 `mobile_seconds`**，改用 `union(sorted(holds))` 重算。
   理由：工具每次按键多算约 **0.121 s 墙钟时间**（7 个独立估计 0.110–0.131，CV 6.5%，
   陈璇 7 个 1.0x 试次为决定性证据），进入视频时间时被倍速缩放
2. **读 holds 必须先排序再取并集**。43 个试次里 **12 个** 数组乱序自嵌套
   （王娟 3 / 徐乐彤 5 / 陈璇 3 / 张 1），朴素求和最多虚高 **+54.8 s（+30%）**。
   "只出现在视频组最后一个"的规律**已作废**，出现位置随机
3. **拒绝入库**：`mobile_seconds == 0` 且 `len(holds) == 0` 且 `unscoreable == false`
   ⇒ 报错。这是"没评"不是"评出 0"，按 0 入库会变成 immobility = 360 s（物理上限），
   一个点就拉歪 r 与 Bland-Altman
4. **零长段记账**（张有 3 个），并集口径下自动为 0，无害但要报出来

输出：43 个试次的重算表（每行给 `union` 值、按键段数、是否乱序、是否零长段、倍速、
`presentation_order`）。**不要在这个 PR 里算 r / ICC / Bland-Altman。**

### DP-013（第二个 PR）：LOVO-CV 框架，**先用合成真值跑通，不接人工数据**

```
for 每个视频 v in 7 个视频:
    在其余 6 个视频的试次上拟合 θ_mob（唯一自由参数，
        目标 = 最小化 |软件 immobility − 人工均值 immobility|）
    在 v 的试次上预测，记录样本外结果
汇总 27 个样本外预测 → r / Bland-Altman
```

- **bout 参数保持 FROZEN，不参与拟合。只拟合 θ_mob 一个标量。**
- 框架必须同时输出**每折拟合出的 θ_mob 值本身**——7 个值的变异系数就是 **G2**，
  这是本项目对 CSI 最有价值的一个数字，别只输出汇总 r 就完事

### 计分窗口：**已不是阻塞项**（DP-004 已降级）

v1 派工单说 `t0_frame` 未定义、多出 26 s 无记录。**已由数据自证**：
三份完整审计 JSON 里有 holds 的 **39 个试次，最大 hold 结束时间无一超过 360.00 s**，

## 4. 提交规程（2026-09-03 更正）

1. 从 **`main`** 开分支（默认分支是 `main` 不是 `master`），前缀 `feat/ fix/ chore/ spike/`，**一分支一关注点**
2. commit 首行 `<type>(DP-###): 摘要`
3. `main` 只接受合并
4. **加任何 ignore 规则后必须 `git check-ignore -q <路径>` 实测。**
   ignore 失效是**静默**的——文件在磁盘上，commit 里没有，等要复现验收结果时才发现真值从未入库。
   两个已实测的坑：`data/` 必须写成 `data/*`（带斜杠会让 git 根本不进目录，后面所有 `!` 例外静默失效）；
   unignore 一个目录后**不要再往里加 `**` 规则**（会重新挡住子目录）
5. **沙箱可以 push（v1 说不能，是错的）**：HTTPS + `~/.git-credentials` 里的 `ghp_` token 可读可写。
   `git push -u origin <分支>` 直接用。**SSH（22 端口握手超时）与 `gh` CLI（`~/.config` 不是目录）不可用**，
   需要打 API 时用 `curl` + 同一 token。`git bundle` 只作离线备份，不是主交付通道
6. **开工前先 `git fetch origin` 并读 `origin/main:docs/STATUS.md`**（DP-023，本单 §0 就是没做这一步的后果）
7. 每个 PR 结束跑 `python3 run_tests.py`，把通过/失败数写进交付说明。**未达标的判据明确写出来，不粉饰**

## 5. 硬约束（全项目适用，任何轨都不例外）

- `assay_core` **只依赖 numpy**。不准引入 OpenCV / scipy
- **禁止像素/帧为单位的判定阈值**。空间用 BL、时间用秒，每个阈值配标度不变性测试。
  例外只有传感器噪声底（属传感器属性），且必须进"噪底台账"显式记账，**不得被当作判定阈值使用**
- **禁止静默兜底**。`panel_band` 已因静默兜底出过两次事故（无行达标时返回整幅高度、
  取"达标行 min..max"把收集盒夹进来），两次都是全程挑错对象且毫无报错。拿不到合理结果就**报警**
- **禁止用自己的输出调阈值**。θ_mob=0.0175 与全部 bout 参数标 FROZEN provisional
- **盲法是工具级硬约束**：`--from-events` 仅允许 `--pool train`；验证池预填直接 SystemExit
- **掩膜口径是测量契约**：改掩膜定义 = 废掉整套阈值标定，须重测（见 SPEC 胶带走廊 §6.9）
