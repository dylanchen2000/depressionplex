### 1.2 时间基准：恢复 Spec A 的三个时钟（R114-03）

首轮本文写过"本项目 t0 完全不存在 ⇒ FST 侧任何'入水后第 N 秒'的说法都无依据，只能报
相对时间（相对首帧）"。这句**把观测缺失当成了时钟定义**，等于自己重写了 Spec A。恢复原样：

**Spec A 的三个时钟**（不是两个，也不是四个）：

| 时钟 | 是什么 | 现状 |
|---|---|---|
| ① **原视频媒体时间** | 源片自己的 pts/帧序 | 在手，14 段源片全量 sha256 + pts 统计 |
| ② **分析素材时间** | CSI 实际吃的转码件的时间轴 | 在手；与①只有**原始 PTS 起点差 +0.54 s 的观测**（15 个 MPEG-1 转码件）——内容级映射是**候选、未复现**（R2-114，见 §1.1 受限行） |
| ③ **实验经过时间** | 从入水（t0）起算的协议时间 | **t0 在本次核对的材料中未取得** |

CSI 输出的时间列、人工秒表的读数，都是**要映射进这三个时钟的观测**，不是新的时钟定义。

**规则（照 Spec A，不改）**：

- t0 **已知** ⇒ 用 `t_source − t0_source` 换算，**t0 可以为负，不许被夹到 0**。
- t0 **未知** ⇒ 出**媒体时间**上的诊断，并标 `protocol_alignment=unknown`。
- **永不**把"第 1 帧"当作"入水那一刻"（Spec A FST-D02 原话：不得自动把录像第 120 秒
  当入水后第 120 秒）。
- **永不**自动裁掉最后 4 分钟、也**永不**宣称通过了标准窗口验收 —— 窗口映射属 FST-D02，
  未确认前只做诊断。
- 诊断层保留 `unknown`，**不改历史主口径**（FST-D03）。

**这条研究路径原 Spec 已经授权**，不需要用户再批一次"能不能开始做诊断"。
需要用户/客户回答的只有一件事：**t0 从哪来**（`DP-134-Q01`，落在 Spec A FST-D02 里），
以及问不到时**如实写 unknown**。

**与 t0 无关、不受影响的一条**：空杯不产出行为秒数（Spec A / DP-125 口径），
G10 空杯门已定死"空杯必须被判成空杯"。
