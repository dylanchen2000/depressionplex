# 备忘：FST 独立研究入口与真实视频分割诊断（DP-136）

日期：2026-09-19　分支：`feat/dp136-fst-research-entry`（从 `47fe7a4` 起）
状态：**研究/原型**。不产正式 CSV、不进验收路径、不借 TST 发布与标定资格。

## 1. 这是什么

Spec A §4–§6 的 A 线第一版：一个**独立的** FST 研究入口
`python -m depressionplex.cli.fst_research`，做四件事：

1. 读**明确身份**的媒体（sha256 + 共用输入身份清单关联，多别名不猜、查不到照实记）；
2. 用通用几何工具对杯体/水线出**提案**（标未确认；CLB 里没讲清出处的数字绝不换算成坐标）；
3. 逐杯分割 + 质量诊断，区分「动物 / 水面反光波纹 / 短时丢失 / 申报空杯」四类状态；
4. 导出叠加短片（带来源 sha、时间、几何、失败原因）——**先证明我们看的是对的动物区域**，再谈候选特征。

| `fst_research/cup_features.py` | 候选特征：刚体平移/旋转与补偿后残差**两个都留**；光流/局部运动 `not_implemented`，不假装 |
| `fst_research/overlay.py` | 纯 numpy 画框/水线/掩膜轮廓/文字 + ffmpeg 短片写出；`refuse_in_repo` 强制产物落仓库外；半截 mp4 删除不留假证据 |
| `fst_research/record.py` | 诊断 JSON 组装/校验/原子落盘；分区不闭合即 raise；sha256、帧数来源、limits 全写进记录。**证据不覆盖**：`write_record`/叠加短片拒写已存在目标；每轮 run 独立目录 `<stem>_run_<时间戳>_<hex8>/`；`_完成清单.json` 只在**全部**产物成功后最后写（逐文件 sha256+bytes），无清单的 run 目录不得当交付证据；记录带 provenance（run_id/代码 SHA+dirty+branch/命令行）与 research_params（每个参数的起点值出处）。**时间加权尾区间（R3 ②）**：`analysis_end_frames` 必填，尾区间=[末抽样帧, 分析末端)取 `min(步长, 末端剩余帧)`——总帧数不整除 step 时按剩余帧计，**不得超过实际视频/分析范围末端**；截断时末端=最后消费帧+1 |
| `fst_research/isolation.py` | A1 路径隔离：静态 AST 审计 + 运行时哨兵，研究入口不得引用 TST 专属判据、`assay_core.rules`、CSI/lovo_cv；`--self-check` 可单独跑 |
| `cli/fst_research.py` | 入口。退出码：0=有杯看得见（或有申报空杯）；3=记录产出但没有一杯看得见；2=守卫拒绝；1=解码/编码失败；4=产物写出失败（失败时只清理**本次** run 目录，旧证据不动）。**空杯申报两条路（R3 ①）**：`--declared-empty`（物理杯号）与 `--declared-empty-channel`（通道号）互斥；通道申报必须配 `--channel-cup-mapping ch=cup` + `--mapping-evidence 依据串` 才应用，否则 `status=mapping_unresolved`、applied=[]、申报照实记录——**applied 只说明程序执行了申报，不表示映射已验证**。**确认件回灌对照（R3 ③）**：`--geometry` 时记录带 `water_body_fallback` 清单（确认件无派生水体区 ⇒ 对比度中值/面积占比分母/静态吸收检查区退回整 ROI），坐标不变的差异先对照该清单归因，不许全算到人工修正几何头上 |

共享模块顺带修了一个真 bug：`GeometryEnvelope.validate()` FST 分支原来用
`one(water_surface)`，多杯（>1 条水线）直接崩；改为 tank↔water_surface
同号配对校验（闭区间压边合法），单实例旧素材行为不变，回归测试钉住。

## 3. 怎么跑

```bash
python -m depressionplex.cli.fst_research 视频.mp4 \
    --out-dir ~/Work/fst_diag/某视频 --cups 4 \
    --manifest docs/共用输入身份清单_v1.csv
# t0 有依据时（依据字符串必填，缺了直接拒）：
#   --t0-source-s -118.0 --t0-evidence "……"
# 申报空杯（1 起）：--declared-empty 2
```

产物（全在 out-dir，**不许**在仓库里）：每轮一个 run 目录
`<out-dir>/<stem>_run_<YYYYmmdd-HHMMSS>_<hex8>/`，内含 `诊断_<名>.json`、
`几何提案_<名>.json`（仅在未给 `--geometry` 时）、`叠加_<名>_杯N.mp4`，
以及最后写出的 `_完成清单.json`。**重跑不覆盖**：同 out-dir 再跑只会新增
兄弟 run 目录，旧证据逐字节不动；任何产物写失败 ⇒ 退出码 4 且只删本次
run 目录。
