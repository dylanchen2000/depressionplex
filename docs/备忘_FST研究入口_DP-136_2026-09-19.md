# 备忘：FST 独立研究入口与真实视频分割诊断（DP-136）

日期：2026-09-19　分支：`feat/dp136-fst-research-entry`（从 `47fe7a4` 起）
状态：**研究/原型**。不产正式 CSV、不进验收路径、不借 TST 发布与标定资格。

## 1. 这是什么

Spec A §4–§6 的 A 线第一版：一个**独立的** FST 研究入口
`python -m depressionplex.cli.fst_research`，做四件事：

1. 读**明确身份**的媒体（sha256 + 共用输入身份清单关联，多别名不猜、查不到照实记）；
2. 用通用几何工具对杯体/水线出**提案**（标未确认；CLB 里没讲清出处的数字绝不换算成坐标）；
3. 逐杯分割 + 质量诊断，区分「动物 / 水面反光波纹 / 短时丢失 / 申报空杯」四类状态；
4. 导出叠加短片（带来源 sha、时间、几何、失败原因）——**先证明我们看的是对的动物区域**，再谈候选特征。

## 2. 模块图（全部新增，路径隔离由测试钉住）

| 模块 | 职责 |
|---|---|
| `fst_research/timeline.py` | 三钟分离（媒体/分析/协议）；t0 未知 ⇒ `protocol_alignment=unknown`，不套 (120,360) 标准窗、不自动截最后 4 分钟；截断/缺口如实上报；台账缺项写 missing，不许填 0 |
| `fst_research/cup_geometry.py` | 杯体/水线提案：中值帧水体连通域 + 结构过滤（每条过滤写进 problems）+ 行梯度旁证（永不改主值，分歧写 note「脚本不选边」）；人工确认件走 `load_confirmed`（半确认/错范式/缺角色一律拒） |
| `fst_research/cup_perception.py` | 逐杯四态分区（observed/unclear/lost_short/declared_absent），分区必须闭合；短时丢失≠空杯；静态动物被背景吸收必须报；空杯只认人工申报且不输出 0 秒行为 |
| `fst_research/cup_features.py` | 候选特征：刚体平移/旋转与补偿后残差**两个都留**；光流/局部运动 `not_implemented`，不假装 |
| `fst_research/overlay.py` | 纯 numpy 画框/水线/掩膜轮廓/文字 + ffmpeg 短片写出；`refuse_in_repo` 强制产物落仓库外；半截 mp4 删除不留假证据 |
| `fst_research/record.py` | 诊断 JSON 组装/校验/原子落盘；分区不闭合即 raise；sha256、帧数来源、limits 全写进记录 |
| `fst_research/isolation.py` | A1 路径隔离：静态 AST 审计 + 运行时哨兵，研究入口不得引用 TST 专属判据、`assay_core.rules`、CSI/lovo_cv；`--self-check` 可单独跑 |
| `cli/fst_research.py` | 入口。退出码：0=有杯看得见（或有申报空杯）；3=记录产出但没有一杯看得见；2=守卫拒绝；1=解码失败 |

共享模块顺带修了一个真 bug：`GeometryEnvelope.validate()` FST 分支原来用
`one(water_surface)`，多杯（>1 条水线）直接崩；改为 tank↔water_surface
同号配对校验（闭区间压边合法），单实例旧素材行为不变，回归测试钉住。

## 3. 怎么跑

```bash
python -m depressionplex.cli.fst_research 视频.mp4 \
    --out-dir ~/Work/fst_diag/某视频 --cups 4 \
    --manifest docs/共用输入身份清单_v1.csv
# t0 有依据时（依据字符串必填，缺了直接拒）：
#   --t0-source-s -118.0 --t0-evidence "……"
# 申报空杯（1 起）：--declared-empty 2
```

产物（全在 out-dir，**不许**在仓库里）：`诊断_<名>.json`、
`几何提案_<名>.json`、`叠加_<名>_杯N.mp4`。
