# CSI 操作单 01：装机与开机自检

> 给操作这台 Windows 机器的人。**按顺序做，每一步做完再做下一步。**
> 任何一步和这里写的不一样，**停下来问，不要猜着往下做。**

---

## 第 1 步：把视频拷过去

Mac 上的文件夹：`~/Work/csi_in/`（约 1.6 GB，17 个文件）

整个文件夹拷到 Windows 机器上，**放在纯英文路径下**，建议：

```
D:\csi_in\
```

> **不要放在「桌面」、「我的文档」或任何带中文的路径里。**
> 2005 年的软件对中文路径不一定处理得了，这是最容易白折腾半天的地方。

拷完对一下文件数：应该是 **14 个 `_x2.mpg` + 2 个 fallback + 1 个 CSV = 17 个**。

---

## 第 2 步：确认软件版本，并且**先只关心 FST**

装了两个程序：

| 程序 | 对应实验 | 手册版本 |
|---|---|---|
| **ForcedSwimScan** | 强迫游泳 FST | 2.0 |
| **TailSuspScan** | 悬尾 TST | 1.0 |

**先做 ForcedSwimScan（FST），做通了再做悬尾（03）。**

> 为什么这个顺序：**ForcedSwimScan 2.0 有批处理，TailSuspScan 1.0 没有**——
> 悬尾那 7 段必须一段一段手工做，是最费时间的一份。
> 所以先用游泳这边花最小的代价确认两件事：许可证能用、我们的视频格式能打开。
> 这两条只要有一条不成立，悬尾那份工做多少都是白做。
> **悬尾不是不做，是排在后面。**

打开 ForcedSwimScan，点 **`Help` → `About ForcedSwimScan`**，
**把这个窗口截图**（版本号、许可证状态都在上面）。

---

## 第 3 步：许可证自检 —— 这一步不过就别往下走

开程序的时候如果弹出一个写着 **Demo Mode** 的提示框：

> **停。这条路走不通，不要继续。**
>
> 手册原文：Demo 模式**只能分析自带的演示视频**，
> **不能打开你自己的视频，也不能修改分析设置**。
> 也就是说 Demo 模式下这件事一件都做不了。

Demo 模式的解法不在你这一步，需要先拿到许可证。请把这三样发回来：

1. 那个 Demo 提示框的截图；
2. `Help → About` 窗口的截图；
3. 加密狗插上之后，Windows 设备管理器里能不能看到它（截图）。

> 说明：**这两本手册里根本没提加密狗**，写的是「安装绑定的许可证密钥文件」——
> 在 `About` 窗口里点 `Register`，导出一个 `.LRQ` 申请文件，
> 拿到密钥文件再回来注册。加密狗可能是别的 CSI 产品用的。
> 所以先别急着到处插拔，把上面三张图发回来我判断。

**没有弹 Demo 提示** ⇒ 许可证是好的，继续第 4 步。

---

## 第 4 步：能不能打开我们的视频（5 分钟就能知道）

**只测一段，不要一次全上。**

1. `File → Open Analysis`（或左上角打开文件夹的按钮）。
2. 弹出的窗口有 6 项，**这一次只填两项，其余全部留空**：

   | 项 | 填什么 |
   |---|---|
   | 1. MPEG Video | `D:\csi_in\FST_ctrl_1to4_x2.mpg` |
   | 2. Background | **留空** |
   | 3. Current Tank | **留空** |
   | 4. Settings File | **留空**（留空就是用出厂默认值，这正是我们要的） |
   | 5. Output Folder | 新建一个 `D:\csi_out\`，选它 |
   | 6. Body Part Classifier | `DT1.dt`，在 ForcedSwimScan 安装目录下的 `Data\PostClass\` 里 |

3. 点 `OK`。**会弹警告说背景文件不对或缺失，这是正常的，点 OK 跳过。**
4. 现在看视频窗口里**有没有出现画面**。

| 现象 | 说明 | 怎么办 |
|---|---|---|
| 画面正常出来了 | 格式对了 | **去 02 继续** |
| 一片黑 / 报错 / 没反应 | `.mpg` 读不了 | 换 `FST_ctrl_1to4_x2_fallback.avi` 再试一次 |
| avi 也不行 | 两种都读不了 | **停，把报错截图发回来**，我换编码重出 |

> 试 fallback 的时候，重复第 2 步，只把第 1 项换成 avi 那个文件。

---

## 第 5 步：把出厂默认参数截图存档（**这一步不许省**）

视频能打开之后，**先别急着分析**，先做这件事：

1. `Tools → Settings`。
2. 面板上有 4 个标签页：**General / Body Setting / Motion Setting**，还有一个第 4 个。
3. **每一个标签页都截图**（Win+Shift+S 框选，或直接手机拍屏）。
   要能看清每个输入框里的数字。
4. 截完，**什么都不要改**，点 `Save Settings`，
   存成 `D:\csi_out\CSI默认参数_冻结.set`。
5. **从这一刻起，这个 `.set` 文件就是本批唯一的设置。**
   后面每段视频的第 4 项都填它。不再进 Settings 面板，不再改任何数字。

> **为什么非要截图**：决定"不动时长"的那十来个阈值，
> 手册**没有写默认值是多少**（原文只说"没有单位，是相对量，靠试错自己定"）。
> 那些数字只存在于你这台机器的屏幕上。
> 截图交回来，这批结果才是可复现的；不截图，将来谁也说不清这个数是怎么来的。

---

## 一句话总结

这份操作单只干一件事：**确认软件能用、把出厂参数冻结下来。**
一个参数都不要调。调参这件事本轮完全不做。
