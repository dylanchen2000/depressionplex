# DP-071-R：残差分子换口径的正面对比（结论：留而不用）

**一句话**：DP-071 查出的 0.5 px 死区是真的，把它补掉之后判据**变差**——
帧级 AUC 中位 −0.017、25/26 试次为负 ⇒ 按跑之前写死的规则，**不翻默认**。
距离场口径作为可选项留在代码里，等高分辨素材到位再评。

## 背景：为什么会有这一步

`residual = area(warp(prev) XOR cur) / BL²`。第二步 `warp` 的存在只为抵消
相机抖动与悬吊小鼠的被动钟摆。DP-071 发现：对**二值**掩膜，「双线性采样 + 0.5 阈值」
等价于把位移四舍五入到最近整数像素 ⇒ 量化下限恰好 **0.5 px**；而不动帧的估计位移
中位只有 **0.106 px** ⇒ 补偿在最需要它的那批帧上**逐位空转**（空转率中位 78%）。
DP-071 已用算术排掉「升采样」「软掩膜」「1 px 容差 XOR」三条修法，只剩距离场。

## 修法本体与四条硬性质

warp 的不再是掩膜，而是**有符号距离场**；残差是两侧**覆盖率**
`clip(0.5 − phi, 0, 1)` 之差的 L1。半像素约定（内部贴边 −0.5、外部贴边 +0.5）
让场沿法向的梯度是每像素 **1**，于是"把场平移 u 像素"就等于"把边界搬动 u 像素"。

| 性质 | 实测 |
|---|---|
| `coverage(signed_distance(m))` 还原掩膜 | 逐位相等，小数覆盖率像素 **0 个** |
| 亚像素线性 | 周长 124 上每 1 px 位移读 54.0 px；u=0.05 读 **2.700** = 0.05x54.0 |
| 同一批位移下的旧口径 | u=0.05…0.49 一律 **0 px**（死区） |
| 整数位移下两口径 | **逐位相等** ⇒ 是同一测量的亚像素延拓 |
| 两帧完全相同 | 残差**恰好 0**（区别于已否掉的软掩膜修法） |

## 合成序列上读数就是反的

| 序列 | 硬 XOR | 距离场 |
|---|---|---|
| 钟摆（被动摆动，应当低） | mean **0.00760** / max 0.01025 | mean **0.01277** / max 0.01456 |
| 关节（真动作，应当高） | mean **0.03921** / min 0.02305 | mean **0.04111** / min 0.02305 |
| 区分度（均值比） | **5.16** | **3.22** |

这触发了 `test_pendulum_residual_near_zero` 与 `test_pendulum_vs_articulated_separation`
两条既有测试。它们的 docstring 写着「任何抬高噪声底的改动都应让本测试失败」⇒
**是探针正常发火**，所以没有放宽阈值，而是去做真数据 A/B。

**顺手排掉一个候选解释**：若抬高的只是「刚体拟合本来就有的亚像素误差、以前被死区
四舍五入掉了」，那在新的**平滑**代价上做亚像素精修（±0.6 px / ±1.5°）应当把钟摆压回去。
实测钟摆只降 **1.7%**（0.01277 → 0.01255），关节却降 **24%**（0.04111 → 0.03130），
且 |dy| 中位 0.60、|dtheta| 中位 2.00° **双双顶到搜索边界** ⇒ 精修仍然是
「把关节运动当刚体吸收」，DP-071 原来那条否决在换了代价函数之后依然成立。

判定门槛写在该脚本的 docstring 里，**在跑之前就写死**：ΔAUC 中位 ≥ +0.02 且
≥2/3 试次为正 且门槛离散度没变差 ⇒ 翻默认；中位 ≤ 0 ⇒ 错方向；其间 ⇒ 分不出。

## 结论落到代码里的样子

- `DEFAULT_RESIDUAL_MODE = "binary_xor"`（不变），`"sdf_coverage"` 作为可选口径保留。
- 两个口径**各有**基线测试钉住：旧口径 0.0070/0.0103，新口径 0.01277/0.01456 ⇒
  换口径的代价永远看得见，不会随时间被忘掉。
- 留着代码的两条理由：① 死区是代码级恒等式，换高分辨相机后分子的整像素分辨率
  不再是瓶颈，这条口径**可能反转**，那时改一个常量就能重测；② 它是
  「不动 ⇒ 恰好 0 残差」的唯一实现，是别的分析（如光栅化噪声估计）的工具。

## 一个必须记住的方法论副产物

距离场口径把**门槛离散度改善了**（极差比 19.4x → 9.3x、CV 51.4% → 37.2%），
AUC 却整体变差，rho(BL, 门槛) 还更负（−0.785 → −0.815）。
⇒ **给所有试次加一个共同的底噪就能压低极差比，却不会让任何一帧更好分。**
⇒ **离散度单独不构成判据。** DP-073 评「换分母」时必须同时报 ΔAUC。
