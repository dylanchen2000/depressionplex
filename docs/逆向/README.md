## 引用规则（三条，违反会把结论读反）

1. **聚合数字一律引第三份**（全量 27 试次）。第二份的 `r=0.958 / MAE 14.57 s` 是
   8 试次子集，第二份自己在开头就声明被取代了；引它当"CSI 的准确度"是错的。
2. **它们没有运行过原始 EXE**。所有算法结论来自静态反编译 + 产物交叉验证，
   三份报告都自己写明了这条边界。凡是"CSI 运行时如何"的说法，都是**未验证**。
3. **人工评分是同一批数据**。第三份用的 35 份人工记录就是我们
   `data/human_scores/` 那批，不是独立第二数据集 ⇒ 它与我们的数字对不上时，
   **是两条流水线之一有 bug**，不是"两个来源有分歧"。
