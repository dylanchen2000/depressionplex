# 给同事的任务：**步骤复核**（2026-09-04）

> **一句话**：不是让你重做实验，也不是让你重评分。
> 是请你把**你实际是怎么做的**说清楚——尤其是**切视频那一步**。
> **总共约 40 分钟**，分四小件，从上往下做，做到哪算哪。

---

## 为什么找你做这个（30 秒背景，看完更好答）

7 段录像本该切出 **28 个小视频**（7 段 × 4 个隔间），实际只有 **27 个**。
少的那一个是 `30mg 2周` 这段的**第 4 个隔间**——那个隔间**从头到尾没放老鼠**，所以当时没切。

**这不是错，做法是对的。问题是"没留下记录"**：文件少了一个，但没有任何地方写"这里是空的"。
结果我们花了好几天在猜"是不是丢文件了、是不是老鼠掉下来了"。

而且**两次异常都出在第 4 个隔间**（另一个是 `20mg 3周` 的第 4 个隔间，那个切了但里面是空的）。
两次都是同一种情况：**没放老鼠**。所以想请你说说，装隔间和切视频这两步实际是怎么走的。

---

## 第 1 件（约 15 分钟）：说清楚你实际的操作步骤

**请照实说，不用说"应该怎么做"。做得不规范也没关系，我们要的是真实情况，不是标准答案。**
可以写几句、可以录段语音、也可以口头说给道俊转达。

| # | 问题 | 你的回答 |
|---|---|---|
| 1 | 一次录像里，**4 个隔间是按什么顺序装老鼠的**？（1→4？还是随手装？） | |
| 2 | 装完之后，**开录之前会不会数一遍"4 个都装上了"**？还是直接开录？ | |
| 3 | 如果这一批老鼠**不够 4 只**（比如只有 3 只），你会怎么办？空着录？还是挪一下位置？ | |
| 4 | **切视频用什么工具切的**？（软件名字就行） | |
| 5 | 切的时候是**一段一段手动框出 4 个隔间**，还是有固定的框/模板？ | |
| 6 | 切出来的小视频**文件名怎么起的**？（比如 `30mg 2周-ch4` 这种，是手打还是自动？） | |
| 7 | 切完之后，**会不会核对"这段应该出 4 个，我这儿是不是 4 个"**？ | |
| 8 | 切的时候**发现某个隔间是空的，你当时怎么处理的**？（跳过不切？切了但不发？还是别的） | |
| 9 | 空隔间这件事，**当时有跟谁说过 / 记在哪儿过吗**？ | |
| 10 | 你觉得**第 4 个隔间是不是比另外 3 个更容易出岔子**？（位置最里面？光线最差？最后一个装？） | |

**第 8、9 题最重要。** 我们要判断的是"以后怎么把空隔间留成一条记录"，
不是追究谁漏了——**漏了是流程没设计，不是人的问题。**

## 第 2 件（约 5 分钟）：顺手确认一件事

打开 `30mg 2周.mp4`，**只看最右边那个（第 4 个）隔间**，拖到几个位置看一眼：
开头、中间、结尾。

回答一句话就行：

- [ ] **一打开就是空的，全程都没老鼠**
- [ ] 一开始有老鼠，后来掉了（大概在第 ___ 分钟）
- [ ] 说不清 / 看不出来

> 这个我们已经从三个方向推出来是"全程空"，但**推出来的和你亲眼看到的不是一回事**，
> 所以还是想请你确认一下。**不用看完 6 分钟，拖着看 2 分钟就够。**

## 第 3 件（约 15 分钟）：写下"哪里觉得别扭"

上次你说的那句——**"刚抬起来发现安静时间很短，不抬起来发现安静的时间很长，没法预判"**——
是这一轮里对我们最有用的一条信息，比多评几个视频值钱得多。它直接让我们把一条错的评分规则整条废掉了。

所以这次也想请你**主动挑刺**，随便写，想到几条写几条：

1. 评分规则里，**哪一条你觉得根本没法照着做**？
2. 用秒表工具的时候，**哪一步最烦 / 最容易点错**？
3. 有没有哪次你**明明想改上一次的判断，但工具不让你改**？
4. 装老鼠、录像、切视频这三步里，**哪一步你觉得最容易出错**？

**不要客气，不要挑好听的说。** 说流程哪里烂比说哪里好有用。

## 第 4 件（下一批录像时才做，10 分钟）：走一遍新清单

下次录像 + 切视频的时候，请按下面这张清单做一遍，**勾完拍张照发回来**。
以后这就是固定动作。

**录像前**
- [ ] 4 个隔间都装了老鼠 → 装了 ___ 只
- [ ] 有空着的隔间 → 空的是第 ___ 个（**空着也要照录，不要挪位置补**）
- [ ] 空隔间**写在纸上/记在文件名里**了

**切视频后**
- [ ] 这段录像应该出 ___ 个小视频，我实际切出了 ___ 个
- [ ] 两个数**不一样**的话，差的那个是第 ___ 个隔间，原因是 ___（大概率是"空的"）
- [ ] 空隔间**也建一个记录**：可以是一个空文本文件 `30mg 2周-ch4-空隔间.txt`，
      也可以在批次表格里写一行。**关键是别让它凭空消失。**

> 为什么要这么麻烦：少一个文件，我们在后面看不出是"空的"还是"丢了"，
> 这两件事的处理方式完全不同（空的要当阴性样本用，丢的要去找）。
> **写一行字，省我们几天。**

## 明确**不要**做的（避免白花时间）

| 不要做 | 为什么 |
|---|---|
| 不要重评已经评过的视频 | 中途换口径会在同一个人身上造成前后断裂，比现在的问题更难处理 |
| 不要为了"数据完整"把 27 个都补第二个人 | 人工评分现在是**辅助**不是主要证据，人时应该花在别处 |
| 不要看软件跑出来的结果再回答上面的问题 | 会把唯一的参照物污染掉 |
| 不要用 0.25 倍速 | 一个视频要 25 分钟，0.5 倍速 12–15 分钟就够 |
